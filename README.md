# USB-CAN-A Async Rust Library

An async Rust library for USB-CAN adapter communication using `tokio-serial`.

Uses [`zencan-common`](https://docs.rs/zencan-common) for CAN message types (`CanId`, `CanMessage`).

# how to use
```toml
usb-can-a-rs = { git = "https://github.com/Carbohydrate-42/usb-can-a-rs" }
```
